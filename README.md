# SWYNEX-PROCESS-ANALYSIS
A case analysis on COVID-19 mRNA vaccine
project: Process and Case Analysis of the Pfizer–BioNTech COVID-19 Vaccine (BNT162b2)

Organisation: SWYNEX Technologies

Internship: Biotechnology Internship

About this project

This project explores the manufacturing process of mRNA vaccines through a case analysis of the Pfizer–BioNTech COVID-19 vaccine.

Topics covered

Overview of mRNA vaccine manufacturing

Major stages of production

Quality control and quality assurance

Ethical considerations

Manufacturing challenges and possible improvements
